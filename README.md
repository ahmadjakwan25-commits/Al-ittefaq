# আল-ইত্তেফাক — সেটআপ গাইড

ইত্তেফাকুত ত্বলাবা ওয়াল উলামা (৪নং চর নতুন পাড়া, ইসলামপুর, জামালপুর) এর ওয়েব অ্যাপ।

## ফাইল
- `index.html` — পুরো অ্যাপ
- `data.json` — সদস্য, আয়-ব্যয়, ঘোষণা ও সংগঠনের তথ্য (অ্যাডমিন প্যানেল থেকে আপডেট হয়)
- `icon.jpg` — লোগো (অ্যাপ আইকন)
- `manifest.json`, `sw.js` — হোমস্ক্রিনে ইনস্টল ও অফলাইনের জন্য

## GitHub Pages-এ চালু করা
1. GitHub-এ নতুন রিপোজিটরি খুলুন (Public), যেমন `al-ittefaq`।
2. এই ৫টি ফাইল আপলোড করুন (Add file → Upload files)।
3. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save।
4. ১-২ মিনিট পর `https://আপনার-ইউজারনেম.github.io/al-ittefaq/` এ অ্যাপ পাবেন।

## গোপন অ্যাডমিন প্যানেল
- অ্যাপের উপরে **লোগোতে ৭ বার দ্রুত ট্যাপ** করুন (অথবা লিংকের শেষে `#admin` যোগ করুন)।
- প্রথমবার পাসওয়ার্ড সেট করতে বলবে।
- ট্যাব: সদস্য · আয়-ব্যয় · নোটিফিকেশন · সংগঠনের তথ্য · সেটিং।

## পরিবর্তন সবাইকে দেখানো (প্রকাশ করা)
GitHub Pages-এ সার্ভার নেই, তাই অ্যাডমিন প্যানেল GitHub API দিয়ে `data.json` আপডেট করে।
1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate।
2. Repository access: শুধু `al-ittefaq` রিপো। Permissions → **Contents: Read and write**।
3. টোকেন কপি করে অ্যাডমিন → সেটিং ট্যাবে বসান, তারপর **প্রকাশ করুন** চাপুন।
4. টোকেন শুধু ওই ডিভাইসের ব্রাউজারে থাকে। কারও সাথে শেয়ার করবেন না।

## নোটিফিকেশন সম্পর্কে
ঘোষণা যোগ করলে সদস্যরা অ্যাপ খুললে 🔔-এ লাল সংখ্যা দেখবে, আর অনুমতি দিলে ব্রাউজার নোটিফিকেশনও পাবে। অ্যাপ বন্ধ থাকা অবস্থায় ফোনে পুশ পাঠাতে আলাদা সার্ভার (যেমন Firebase) লাগবে — পরের ধাপে করা যাবে।

## নিরাপত্তা নোট
- সদস্যের ফোন নম্বর শুধু অ্যাডমিন প্যানেলে দেখা যায়, পাবলিক পেজে নয়।
- কিন্তু `data.json` পাবলিক রিপোতে থাকে, তাই ফাইলটি সরাসরি খুললে ফোন নম্বর দেখা সম্ভব। স্পর্শকাতর তথ্য না রাখাই ভালো, অথবা রিপো Private রেখে অন্য হোস্টিং ব্যবহার করুন।
- সবসময় মাঝে মাঝে "ব্যাকআপ ডাউনলোড" করে রাখুন।
